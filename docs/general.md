# Документация model_interface

## Общее описание
Пакет `model_interface` предоставляет унифицированный интерфейс для работы с различными моделями в проекте VLMHyperBench. Он содержит базовые классы, утилиты и фабрики для инициализации и использования моделей.

## Архитектура
- `model_factory.py` - фабрика для создания и инициализации моделей
- `model_interface.py` - базовый интерфейс модели
- `model_utils.py` - утилиты для работы с моделями

## История изменений

### 2025-07-24: Перенос функции load_model_config
Функция `load_model_config` была перенесена из скрипта `run_structure_out_invoice.py` в модуль `model_utils.py` по следующим причинам:

1. **Централизация функциональности** - функция является общей утилитой для загрузки конфигурации моделей и должна быть доступна всем компонентам проекта
2. **Повторное использование** - теперь функция может использоваться любым модулем, которому требуется загрузка конфигурации модели
3. **Соблюдение принципов модульности** - логика работы с моделями сосредоточена в одном пакете
4. **Упрощение поддержки** - изменения в логике загрузки конфигурации теперь требуют правки только в одном месте

Функция добавлена в `model_utils.py` как часть общих утилит для работы с моделями, что соответствует архитектурным принципам проекта.
